# 快速精度测试工具（AcuRev-100 / ACmeter）

AcuRev-100 快速精度测试 GUI 工具：CL3021 交流源逐点控源 + Modbus RTU 读寄存器 + 精度判定 + 报告导出。

默认参数取自项目单一配置源 `projects/AcuRev100/config.yaml`（精度阈值、源参数、电流限幅、
供电护栏、台体 CT 换算、串口号），读不到时回退内置默认值——目录整体拷走仍可独立运行。

---

## 🔴 跑测前置（必须逐条确认）

1. **电表背面 Dip Switch 已解锁**：铅封锁定（Sealing Status 0x1040 = 0x0A）时接线/CT/频率
   配置写入会被拒（exception 1），工具会中止并提示。解锁期间 LCD 常驻
   "Remote Configuration Mode" 弹窗。
2. **电流注入方式与 config 一致**：`source.current_injection` = `via_ct`（经台体 CT，≤25A）
   / `direct`（直连 mA 输入，**禁超 0.1A**）。换接线必须同步改——2026-07-09 曾因此烧板。
   同时确认 `source.max_current_a_phase`（逐相上限，当前 A/B 20A、**C 15A**）与台面回路一致：
   C 相超 15A 会让源报 "Ic 过载"。
3. **电表自供电**：电源取自 CL3021 的 Va/Vn。本工具全程用保活点，不关源、不退 AC 版面；
   请勿在测试期间手动归零源输出。
4. **Acuview2 与本工具串口互斥**：电表 RS-485 口通常被 Acuview2 占用，本工具默认走
   **USB 校验口**（config `transport.rtu.port`，当前 COM7）。

## 使用流程

1. **连接电表**：串口/波特率/Slave ID 默认已按 config 填好，点【连接电表】变绿即可。
2. **连接源**：TCP/UDP 模式（实为 UDP）→【连接源】。UDP 模式自动使用 `SourceUdp`
   （逐帧带 ACK、逐点档位、同值角度帧跳发）。
3. **加载 Modbus 地址表**（可选）：`modbus_addr/` 目录唯一 xlsx 时自动填入，点【加载】按
   Description 列覆盖内置地址；不加载则用内置 RACG 地址。
4. **测试配置**：

| 配置项 | 说明 |
|--------|------|
| CT 类型 | 按 `config device.model` 联动（mA 型 100mA / mV 型 333mV） |
| 测点文件 | 默认 `test_point/acurev100_test_case.xlsx` |
| 接线方式 | 多选：1E2W / 2E3W1P / 3E4WY |
| 源稳定等待 | 每点设源后等待秒数（默认取 config `source.settle_s`） |
| 采样间隔/次数 | 默认 200ms / 10 次（config `run.sample_n`） |

5. **换线提示 + 接线自检**：只有 **3E4WY** 需要单独换线（需接入 B 相），测到时弹窗+蜂鸣
   等待确认；1E2W 与 2E3W1P 共用同一套物理接线，可连续测。
   确认后引擎会先做**接线自检**：在 **30V / 0A** 上给该接线应带电的相加压，读电表的 Ub/Uc
   验证端子确实接到了电表；读到 ≈0V 就立刻降压中止并提示，不会在 120V+ 上持续过载。
6. **查看结果**：
   - 右侧实时监控每 200ms 刷新（当前/最小/最大/平均 + 误差%，超门限着色）
   - 底部结果表格：绿行=全 Pass，红行=有 Failed
   - 报告：`results/Precision_Measure_{接线}_{时间戳}.xlsx`（每点即存盘，中途停止不丢数据）

## 测试点文件格式

由 `test_point/gen_acurev100_testpoints.py` 生成，sheet：`test_case_mA` / `test_case_mV` / `说明`。

| 列索引 | 字段 | 说明 |
|--------|------|------|
| 0 | test_case | 用例编号（RACG_caseN） |
| 1-3 | Ua / Ub / Uc | 相电压（V） |
| 4-6 | Ia / Ib / Ic | **源侧输出电流（A）**，非电表读数 |
| 7-9 | Va/Vb/Vc_angle | 电压相角（°） |
| 10-12 | Ia/Ib/Ic_angle | 电流相角（°） |
| 13 | 等待时间(h) | 保留列（精度测试恒 0） |
| 14 | PF | 参考列（1.0 / 0.5L / 0.8L / 0.5C / 0.8C） |
| 15 | 接线方式 | 1E2W / 2E3W1P / 3E4WY |
| 16 | 频率 | 50 / 60 Hz |
| 17-22 | 精度阈值 | 电压/电流/相角(°)/有功/无功/视在 |
| 23-24 | 采样次数 / 间隔(s) | |
| 25 | CT_Primary(A) | 期望值换算用（默认 200A） |
| 26 | 备注 | 含"宽口径"= 该行阈值有意偏离 config，跳过一致性复核 |

**电流换算**：`电表期望读数 = 源侧输出电流 × CT Primary ÷ 台体CT额定`
（mA 型 ÷20，mV 型 ÷5；见 config `source.bench_ct_a`）。

**精简矩阵**（每接线 17 点 × 3 接线 = 51 点/sheet）：
电流覆盖额定 100%（满载）/75%/50%/10%/Imin(1%)/Ist(0.1%)；PF 1.0/0.5L/0.8L/0.5C/0.8C；
50Hz 为主 + 末尾 2 个 60Hz 点（写频率选择要吃 90s 延迟重启窗口）；
**同频率的点连续排列**（频率切换是唯一会掉源输出的动作，60Hz 排末尾使每种接线只切一次），
同 PF 的点也连续（角度帧带 freq 字段，同值可跳发）。
矩阵**按完整覆盖编写**，不把某台源的个体能力写进测点文件——见「源能力开关」一节。

按接线方式的电压与相角（🔴 2026-07-27 实机修正）：

| 接线 | 相电压档 | 电压相角 Va/Vb/Vc | 未接线相 |
|---|---|---|---|
| 1E2W | 120 / 220 / 277V | 0 / 240 / 120 | **B、C 相不出压不出流** |
| 2E3W1P | 120 / 220 / **240V** | 0 / 240 / **180**（分相 A+C 反相） | **B 相不出压不出流** |
| 3E4WY | 120 / 220 / 277V | 0 / 240 / 120 | — |

- **未接线相必须零输出**：1E2W 给 B 相加压时源报 "Ub 过载" 并进保护锁存（台面未接线相的
  电压端子并接/接 N），引擎在 `_source_point` 里按接线方式强制清零，与测点表内容无关。
- **2E3W1P 是分相**：Vc 相角 180°（不是 120°），线电压 Uca = 2×相电压；因此高压档取 240V
  （2×240=480V 恰在 CAT III L-L 上限，取 277V 会到 554V 超规格）。口径同已实跑用例 009_02。

## 源能力开关（逐相电流上限）

某台 CL3021 的某相出不到额定电流时，用 config 的**逐相上限**把相应测点在运行时跳过，
矩阵与报告口径都不用改：

```yaml
source:
  max_current_a_phase:      # 源侧逐相上限(A)；描述"这台源的能力"，不是产品/测点口径
    a: 20.0
    b: 20.0
    c: 15.0                 # ← 当前这台源 Ic 出不到 20A（换正常源改回 20.0 即全跑）
  over_phase_cap: skip       # skip=跳过并留证(默认) / abort=中止本批
```

- 超相限的测点：状态栏 `⏭ 跳过 …`、GUI 结果表灰行、报告该行备注写 `[SKIPPED] 未执行：IC=20A 超本源该相上限 15A`
  且各量块留空（不会被误算成 Pass），进度条照常推进。
- **换正常源只改这一处配置，测点文件不用重新生成**。
- 当前配置下的实际影响（mA 型台体 20A/100mA）：

| 接线 | 总点数 | 实跑 | 跳过 |
|---|---|---|---|
| 1E2W | 17 | 17 | 0（只有 A 相带流） |
| 2E3W1P | 17 | 13 | 4（各电压档的 100% 额定点） |
| 3E4WY | 17 | 13 | 4（同上） |

> mV 型台体是 5A/333mV CT，满载源侧只需 5A，**三种接线都不受此限、全 51 点可跑**。
> 另注：满载点的源侧电流恒等于台体 CT 额定，与 CT Primary 无关——降 Primary 不能绕过这个限制。
> `SourceUdp.set_point` 内另有一道逐相硬限幅作为兜底，超限直接拒发。

## 精度判定规则

误差 = `(测量值 − 期望值) / 期望值`；**Pass 条件**：`|最小误差|`、`|最大误差|`、`|平均误差|`
三者同时 ≤ 阈值。

- 阈值取自 `config.yaml accuracy` 段：电压/电流/有功 0.2%、无功/视在 0.5%、相角 ±0.5°（绝对量）
- 测点表阈值列须与 config 一致，加载时自动复核并告警
- 期望≈0 的量（如 PF=1 时的无功）改用以 |S| 为参照的绝对带 `±阈值×|S期望|`
- 未接线相的量不判定、报告置空

## 源掉输出 / 测量异常时的行为

AcuRev-100 **只能由 Va/Vn 供电**（USB 口不供电），因此两种失效要分开处置：

| 现象 | 含义 | 处置 |
|---|---|---|
| Modbus 无应答 | 电表没电 ⇒ 源输出掉 0 | 救源：**先回 0A 保活点**拉输出 → 复活后再加幅值 → 不行则冷重臂（联机/切屏/档位模式）重来，最多 3 轮；仍不恢复即**中止整批** |
| Modbus 有应答但频率读不到 | 电表**有电**，测量块在启动窗口或撞上测量恒 0 缺陷 | 不救源（救源是错的处置），放宽等待重判；持续无效则中止并提示可能需【恢复出厂设置】 |

中止而不是跳点：电表没电时继续跑只会把剩余测点刷成空壳；已跑测点的报告已落盘。

### 台面因果模型（哪些动作真的危险）

| 动作 | 会不会掉源输出 | 说明 |
|---|---|---|
| 电流降到 0 | **不会** | Va 在电表就不掉，零电流输出无任何风险 |
| 电流 / 电压档位切换 | 不会 | 可逐点切换（本工具在 0A 上切） |
| 幅值帧（只改幅值） | 不会 | 直接发 |
| **角度帧** | **每发必掉，电表必重启**（6/6 实测） | 0A 上切 + 只发一轮 + 切后等复活再加载幅值 |
| **频率切换** | **会** | 源须在档位模式 + 0A 上切 + 切后验证，掉了即冷重臂重试（3 轮） |

> **2026-07-28 修订（实测推翻上一版）**：100V/0A 上只切角度连切 6 次，目视 6 次表全部重启，
> `DEVICE_RUN_TIME` 每次丢 0.7~1.9s ⇒ **一条用例发几个角度帧，表就重启几次**。
> 判重启别用探活（表 1s 级就起来，探不到）；用 `DEVICE_RUN_TIME`(0x1019) 对墙钟算"丢秒"，
> **阈值须先跑空窗基线标定**（本底 ±0.5s 量化噪声 → 门限 0.6s；拍成 2.0s 会漏判全部重启）。

每个测点的时序：**① 零流版（电压/角度/频率到位、电流 0）→ ② 写电表配置并吃重启窗口 →
③ 把电流加上去**。反序（先改电表频率再改源频率）会让电表在整个 91s 稳定窗里对着**错误频率
的输入**判"已稳定"——2026-07-27 实机 3E4WY case51 即此坑。

### 档位策略：逐点档位 + 20% 选档余量（保源精度又不压满刻度）

`config source.precision_tool_gear_pin: false`（默认）。钉档（480V/20A 全程不切）会让
120V / 2A / 0.02A 这类低幅值点跑在大量程上，**源自身误差可达 0.2% 量级**，直接把电表精度
判定带偏。既然档位切换不掉源、且本工具切换时输出恒为 0A，逐点档位是纯收益。

⚠️ 但**不能压在量程满刻度上**：把 120V 打在 ≤120V 档时三相带载会让源报 "Ub/Uc 过载"
（2026-07-27 实机）。因此选档留 20% 余量（`source_comm.GEAR_HEADROOM = 0.8`）：

| 测点电压 | 选中档位 | 占该档量程 | 对比钉档 480V |
|---|---|---|---|
| 100V（保活） | ≤240V | 42% | 21% |
| 120V | ≤240V | 50% | 25% |
| 220 / 240 / 277V | ≤480V | 46% / 50% / 58% | 同 |

电流档不加余量（精度优先），逐点按幅值选。置 `precision_tool_gear_pin: true` 可回退钉档；
pytest 路径（`tests/helpers_accuracy.py`）不受此项影响，仍用 `gear_pin`。

> 程序侧的切屏重臂**清不掉源侧锁存的过载/保护**，这类情况必须到 CL3021 面板手动复位；
> 中止提示里会同时提醒核对"本接线方式下未接线相是否被误加压"（过载最常见诱因）。
