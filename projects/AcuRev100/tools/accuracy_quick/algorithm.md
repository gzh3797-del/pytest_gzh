# 快速精度测试算法说明（AcuRev-100 / ACmeter）

> 适配自 AcuRev1320 的 `acuvimseries_fast_test.py`，2026-07-27 按 AcuRev-100(RACG) 口径重写。
> 台面结论与 `projects/AcuRev100/tests/helpers_accuracy.py` 同源（自供电、铅封门禁、台体 CT 换算）。

---

## 1. 整体流程

```
TestEngine.start() → 独立线程 _run()
  ├─ 按 CT 类型选测点 sheet（100mA/80mA→test_case_mA，333mV/RCT→test_case_mV）
  ├─ 按接线名筛测点（testpoint_reader.load_testpoints，标签直筛）
  ├─ 阈值一致性复核（测点表 vs config.yaml accuracy）
  ├─ 源初始化：电表在线 → warm_init（不切屏，输出不断）/ 离线 → init（冷初始化重开输出）
  └─ 逐接线 → 逐测点
       ├─ 换线提示（仅 3E4WY；换线期间保持保活输出，电表不断电）
       ├─ 接线自检：30V/0A 低压探该接线应带电的相是否真接到电表（读 ≈0V 即降压中止，见 §6.3）
       ├─ A 相供电护栏（A 相 < 工作下限 → 抬到保活电压，期望值按实际输出重算）
       ├─ 逐相能力过滤（本台源某相出不到该点电流 → 跳过并留证 / 或中止，见 §6.3）
       ├─ 零流版下发：电压/角度/频率先在 0A 上切到目标值并确认源仍出力（见 §6.3）
       ├─ 幂等同步电表配置（接线/CT类型/CT Primary/频率选择）
       │    ├─ 读回比对，只写差异；全一致整组跳过
       │    ├─ 有差异 → 先查铅封 Sealing Status(0x1040)，锁定即中止并提示解锁
       │    └─ 写频率选择后吃满延迟重启窗口（90s）+ 稳定保持（15s），期间失联则救源
       ├─ 源下发测点（电流硬限幅 → 同值角度帧跳发 → 幅值/频率帧 ×2 轮，逐帧校 ACK）
       ├─ 等电表存活 + 测量就绪（频率读值 > 10Hz）
       ├─ 计算期望值（源电流 × CT Primary ÷ 台体CT额定；P/Q/S 由换算后电流算）
       ├─ 连采 N 次读寄存器 → 逐量判定 → 落报告 Excel（每点即存盘）
       └─ 本接线跑完回保活点（🔴 不关源、不退 AC 版面 = 不给电表断电）
```

## 2. 参数体系

### 2.1 CT 类型

| 型号 | 可选 CT | 寄存器值(0x1049/104D/1051) | 测点 sheet |
|---|---|---|---|
| AcuRev-101-mA | 100mA | 0 | test_case_mA |
| AcuRev-101-mA | 80mA | 待固件确认 | test_case_mA |
| AcuRev-101-mV | 333mV | 2 | test_case_mV |
| AcuRev-101-mV | RCT（SRS v1.03 新增） | 待固件确认 | test_case_mV |

型号不可跨切（knowledge context 共存约束）；GUI 下拉按 `config device.model` 联动。

### 2.2 接线方式（Service Configuration 0x1042）

| 代码 | 寄存器值 | 接线 | 参与判定的量 |
|---|---|---|---|
| 1E2W | 0 | 单相，仅 A 相 | Ua, Ia, θ_Ua, θ_Ia, Pa, Qa, Sa, P/Q/S_sys |
| 2E3W1P | 1 | 分相 A+C（B 相端子不接线） | Ua, Uc, Ia, Ic, θ(A/C), Pa, Pc, Qa, Qc, Sa, Sc, P/Q/S_sys, **Uca** |
| 3E4WY | 2 | 三相四线星形 | 全量（含 Uab/Ubc/Uca） |

未接线相的量在报告中整块置空、不判定（`test_engine.VALID_QTY`）。
AcuRev-100 **无中性线电流**（0x9078 为 Reserved），报告不含 In。

### 2.3 电流换算（本工具与 1320 版最大的口径差异）

测点表列 5~7 存**源侧输出电流**，电表读数经台体降流 CT 放大：

```
电表期望读数(A) = 源侧输出电流(A) × CT Primary ÷ 台体CT额定
   mA 型：台体 20A/100mA → 系数 = Primary/20（Primary=200A ⇒ ×10）
   mV 型：台体 5A/333mV  → 系数 = Primary/5 （Primary=200A ⇒ ×40）
```

台体额定见 `config.yaml source.bench_ct_a`；P/Q/S 期望值一律由换算后的电流计算。

## 3. 功率计算（单位与寄存器一致：W / var / VA）

```
Pa = Ua × Ia × cos(θ_Ua − θ_Ia)      [W]
Qa = Ua × Ia × sin(θ_Ua − θ_Ia)      [var]
Sa = Ua × Ia                          [VA]
```

> 1320 版这里除了 1000 返 kW；AcuRev-100 寄存器是 W（220V×50A、PF=1 → 读 11000），
> 沿用 kW 口径会差 1000 倍。

系统功率 = **该接线实际接线相**之和：

| 接线 | P_sys |
|---|---|
| 1E2W | Pa |
| 2E3W1P | Pa + Pc |
| 3E4WY | Pa + Pb + Pc |

线电压由相电压向量差得出：`Uab = |Va⃗ − Vb⃗|`（同理 Ubc / Uca）。

---

## 4. 精度判定

误差 = `(测量值 − 期望值) / 期望值`；**min / max / avg 三者绝对误差同时 ≤ 阈值**才 Passed。

| 量 | 阈值来源（config accuracy） | 判定口径 |
|---|---|---|
| 电压 / 线电压 | voltage 0.2% | 相对 |
| 电流 | current 0.2% | 相对 |
| 有功 | active_power 0.2%（认证 Class 0.5 = 0.5%，测试卡取更严的工程目标） | 相对 |
| 无功 | reactive_power 0.5% | 相对；期望≈0 时改绝对带 |
| 视在 | apparent_power 0.5% | 相对 |
| 相角 | phase_angle ±0.5°（SRS 明文） | **绝对**（含 360° 跨越修正） |

**期望≈0 的量**（如 PF=1 时的无功）：相对误差无意义 → 改用以 |S| 为参照的绝对带
`±阈值 × |S_期望|`（与 `case_map.yaml` 顶部 accuracy_spec 同口径），报告误差列此时存绝对偏差。

测点表阈值列必须与 config 一致，加载时由 `testpoint_reader.check_thresholds` 复核并告警；
有意放宽的行（Ist 点低于 Imin，不在精度等级适用区间）在备注写"宽口径"跳过复核。

## 5. 采样

```python
for _ in range(sample_cnt):          # 默认 10 次（config run.sample_n）
    time.sleep(sample_interval)      # 默认 0.2s
    read_holding_registers(连续块一次读回)   # 地址连续 → 单次 RTU 往返
```

单次采样打在抖动量上是抛硬币（002 批实证：频率 50.0/50.1 交替、电流在判据边界浮动），
故连采 N 次并给出 min/max/avg 三者极值证据。

## 6. 设备控制要点

### 6.1 配置写入（幂等 + 铅封门禁 + 延迟重启）

```
读回比对 → 无差异则整组跳过（免铅封检查、免扰动测量块）
有差异 → 读 Sealing Status(0x1040)：≠0 即中止（锁定时写入被拒，exception 1）
       → 逐个写 → 写了频率选择(0x1041) 则等重启窗口(config run.cfg_restart_window_s, 默认 20s)
         + 连续稳定 8s；等待期间每 10s 播报进度
       → 窗口内失联超 12s ⇒ 补拉保活/冷重臂救源（重启窗口内源输出会掉 0 且不自恢复）
```

不主动写软重启 0x1147：电表写频率选择后自行延迟重启，主动重启只会拖长自供电表的断电窗口。

窗口为何是 20s 而不是 90s：2026-07-13 记录"写 0x1041 后 30~60s 才重启"→ 老口径等满 90s；
2026-07-27 两轮实测（17:01 / 17:37）全程未观察到重启，白等 91s。缩短的安全网是
**采样期重启自动重采**：频率样本里出现 ≤10Hz 即判本次采样被重启打断，等就绪后重采（最多 3 次），
而不是把该点判成 FAIL。要回保守口径把 `config run.cfg_restart_window_s` 改回 90。

### 6.2 源控制（CL3021，UDP 逐帧 + ACK）

- 有效帧序：联机 → 切AC界面 → 档位模式 → 档位 → 角度 → 幅值 → 频率（幅值/频率各发 2 轮）
- **只有频率切换会掉输出**（详见 §6.3）；角度/幅值/档位帧都不掉源
- 角度帧带 freq 字段，故 6 角 + freq 同值时跳发（省一次频率重设，也少一次风险）
- **电流硬限幅**：`config source.max_current_a`（via_ct 25A / direct 0.1A，2026-07-09 烧板事故后硬门禁）
  + `max_current_a_phase` 逐相上限（本台源 Ic ≤ 15A）
- 首次出电流先 0.05A 软启动 2s

### 6.3 台面因果模型（2026-07-28 实测修订版）

| 动作 | 会不会掉源输出 / 打死电表 | 处置 |
|---|---|---|
| 电流输出降到 0 | **完全无风险**（Va 在，电表就不掉） | 随便用；本工具每点必经 0A |
| 电流档位切换 | 不掉源 | 逐点切换（在 0A 上切） |
| 电压档位切换 | 不掉源 | 逐点切换 |
| 幅值帧（改电压/电流值） | 不掉源 | 直接发 |
| **角度帧（仅角度变）** | **每发必掉，电表必重启**（6/6 实测） | 0A 上切 + 只发一轮 + 切后等复活再加载幅值 |
| **频率切换** | 会掉源输出 | 源须在档位模式 + 0A 上切 + 切后验证 + 掉了就冷重臂重试 |

> **2026-07-28 修订（台面目击 + run_time 标定，推翻上一版）**：上一版"角度帧不掉源、只有
> 频率切换才掉"是错的。隔离实验：100V/0A 上只切角度（电压/频率/档位全程不动）连切 6 次，
> **目视 6 次表全部重启**，`DEVICE_RUN_TIME` 每次丢 0.7~1.9s。005/006 是仅有的"角度≠标准
> 三相"用例组，也正是仅有的频繁掉源组；002/003/004 全部命中角度缓存跳发角度帧 → 零重启。
> ⇒ **一条用例发几个角度帧，电表就重启几次**。是"帧带 freq 字段被重写"还是"角度突变本身"
> 尚未隔离，处置相同。
>
> ⚠️ **判重启的两个坑**（都踩过）：
> ① 别用探活——表 1s 级就起来，设点后 settle 2s 再探活第一拍就通，重启整个漏掉；
> ② 用 `DEVICE_RUN_TIME`(0x1019, uint32 秒, 每秒+1, **重启不清零、只丢约 1s**) 判"丢秒"时，
> 阈值必须先跑空窗基线标定：本底 ±0.5s（1s 量化噪声），门限 0.6s。早前拍脑袋定 2.0s，
> 把 6 次真重启全判成"未掉电"（见 tests/helpers_accuracy.py `REBOOT_LOST_S`）。

**角度帧怎么少发（pytest 路径 helpers_accuracy，2026-07-28 落地并实测）**：既然发一帧=重启一次，
省帧就是省重启。三层：

1. **进程内缓存**：6 角 + freq 与上次一致就不发（原有机制）。
2. **跨进程落盘**（`config source.state_file`，默认 `.source_state.json`）：每次角度帧成功下发即
   把角度/电压写盘，下个进程照实况恢复缓存。有了它，**退场不再需要把角度拉回标准三相**——
   那是每条非标角度用例白送的一次重启。进程崩了也不会像常量 `assume_angles` 那样说谎。
3. **电表反证**（跳发前拿表实测电压相角对账，容差 5°）：落盘/常量记的都是"我们发过什么"，
   源实际在出什么从没读回来过；有人手动拨面板就会静默跑错数据。对得上才跳发，对不上作废
   缓存强制下发。实测：谎称标准三相能抓住；正常分离角度确认放行、整条用例 0 重启；
   **近同相角度（如 B=1°）表读数自身秒级乱跳会误报**，后果是白发一帧（失败安全，数据仍对）。

> 会话开场的保活点也必须沿用缓存角度（`_keepalive(src)`）：只看 `last_point` 会在新进程里
> 取到 None → 回落标准三相 → 开场白发一帧。2026-07-28 实测踩过，落盘状态明明一致却仍重启两次。

每个测点的执行时序（把所有切换都放到 0A 上做）：

```
① 零流版测点：电压/角度/频率 = 目标值，三相电流 = 0
     · 频率有变 → 先重发"档位模式"帧（切频率的前提，2026-07-13 实证）
     · 下发后确认电表在线且测量就绪；掉了 → 冷重臂重试（最多 3 轮）
② 写电表配置（接线/CT/CT Primary/频率选择）并吃延迟重启窗口
     · 此时源已在目标频率且 0A ⇒ 电表对着**正确输入**判稳（反序会让 91s 稳定窗判在错频率上）
③ 把电流加到测点值（只变幅值帧；角度帧命中同值跳发）→ 采样
```

**选档余量**：逐点选档时留 20% 余量（`GEAR_HEADROOM=0.8`）——把 120V 打在 ≤120V 档
（满刻度）时三相带载会让源报 "Ub/Uc 过载"（2026-07-27 实机），故 120V 走 ≤240V 档。
电流档不加余量（精度优先）。

**接线自检**：换线确认后先在 **30V/0A** 上给该接线应带电的相加压，用电表读数验证端子接到位；
读到 ≈0V ⇒ 立刻降压并中止（台面疑似仍是上一种接法，B/C 并接或接 N），避免在测点电压下持续过载。

**保活点也遵守"未接线相不加压"**：1E2W 的 B/C、2E3W1P 的 B 在保活/救源时同样输出 0V。

**档位策略**：本工具默认**逐点档位**（`config source.precision_tool_gear_pin: false`）。
钉档（480V/20A 全程不切）虽然省掉切档动作，但让 120V/2A/0.02A 这类低幅值点跑在大量程上，
**源自身误差可达 0.2% 量级**，会把电表的精度判定整片带偏——精度测试不可接受。
既然档位切换本身不掉源、且切换时输出恒为 0A，逐点档位是纯收益。

**逐相能力过滤**：`config source.max_current_a_phase` 描述"这台源各相能出多大电流"
（本台 Ic 出不到 20A），超限测点按 `over_phase_cap` 跳过（默认，报告标 `[SKIPPED]`）或中止本批。
换正常源只改配置、测点文件不动。

**救源顺序**：一律先在 0A 上把输出拉回（先试目标点的零流版，再退到保活点），电表活了再把幅值
加回目标点；不行则冷重臂（联机→切屏→档位模式）重来一遍，最多 3 轮，仍不行即中止本批。

### 6.4 自供电电表

电表电源取自源 Va/Vn：关源 = 断电。因此空闲/收尾一律用保活点（A 相 ≥ 供电下限、0A），
测点 A 相低于下限时强制抬压并在报告备注 `[guard]`（期望值按抬压后的实际输出重算）。

## 8. 结果 Excel 结构

每种接线一个文件：`results/Precision_Measure_<接线>_<时间戳>.xlsx`，每行一个测点：

```
[输入区 25 列] 用例编号 | 接线 | CT类型 | CT Primary | 频率 | 电流换算系数 |
               6 个阈值 | 源侧 U/I/角度 12 列 | 备注
[各量 8 列 × 27 量] 期望值 | 最小值 | 最小误差 | 最大值 | 最大误差 | 平均值 | 平均误差 | 结果
```

着色：min/max 超限黄底，avg 超限红底，Passed 绿底 / Failed 红底；未接线相整块留空。
