这份清单涵盖了从零开始到团队协作中最常用的 Git 操作，按功能逻辑进行了分类，非常适合作为速查表。

---

## 1. 基础配置与初始化

在你开始任何项目之前，通常需要先“亮明身份”。

* **配置用户信息**
```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

```
* **新建仓库**
```bash
git init               # 在当前目录初始化一个新的本地仓库
git clone <url>        # 从远程服务器克隆一个完整的仓库

```

---
## 2. 文件的“生老病死”（提交工作流）

这是你每天用得最多的命令，用于将代码改动保存到版本库。

* **查看状态**
```bash
git status             # 查看哪些文件被修改了、哪些还没提交

```
* **暂存文件 (Stage)**
```bash
git add <file>         # 暂存指定文件
git add .              # 暂存所有修改过的文件

```
* **提交保存 (Commit)**
```bash
git commit -m "说明"   # 提交暂存区内容到本地库
git commit --amend     # 撤销上一次提交，并将当前的修改合并进去（改写最后一次 commit）

```
---

## 3. 分支管理 (Branching)

分支是 Git 的灵魂，建议“多用分支，少在主干直接改”。

* **查看分支**
```bash
git branch             # 查看所有本地分支
git branch -a          # 查看本地和远程的所有分支

```
* **创建与切换**
```bash
git branch <name>      # 创建新分支
git checkout <name>    # 切换到指定分支
git checkout -b <name> # 创建并立即切换到该分支 (常用)

```
* **合并与删除**
```bash
git merge <name>       # 将指定分支合并到当前分支
git branch -d <name>   # 删除本地分支（已合并的分支）
git branch -D <name>   # 强制删除本地分支（未合并的分支）

```
---

## 4. 远程同步 (Remote)

用于和团队成员同步代码。

* **推送与拉取**
```bash
git push origin <name> # 推送本地分支到远程
git pull               # 拉取远程代码并直接合并到当前分支
git fetch              # 仅下载远程更新，不进行合并（更安全）

```
* **清理**
```bash
git fetch -p           # 清理本地那些在远程已经被删掉的分支引用

```
---

## 5. 撤销与“后悔药” (Undo)

写错代码或操作失误时的救命稻草。

* **丢弃工作区修改**
```bash
git checkout -- <file> # 撤销对某个文件的修改，恢复到最后一次提交的状态

```
* **撤销暂存**
```bash
git reset HEAD <file>  # 把文件从暂存区踢回工作区，但保留代码修改

```
* **版本回退 (慎用)**
```bash
git reset --hard <ID>  # 强制回退到某个版本，所有之后的未提交代码都会丢失
git reset --soft <ID>  # 回退到某个版本，但保留你之后的修改在暂存区

```
---

## 6. 临时存放 (Stash)

当你正在开发一个功能，突然需要紧急切换去修复另一个 Bug，但你又不想提交还没写完的代码时：

* **暂时寄存**
```bash
git stash              # 把当前还没提交的改动“藏起来”

```
* **取回寄存**
```bash
git stash pop          # 恢复最近一次寄存的内容，并删除寄存记录
git stash list         # 查看所有寄存的记录

```

---

## 7. 查看记录

* **历史日志**
```bash
git log --oneline      # 简洁地查看提交历史
git log -p <file>      # 查看某个具体文件的详细修改历史

```
