## 三、设备类型

| 类型 | 说明 | 约束 |
|------|------|------|
| Physical | 物理电表（Acuvim II/III） | 需绑定硬件 SN |
| Gateway | AcuLink810 网关 | 有下挂设备时禁止直接删除 |
| Calculated | 计算表，公式：`$deviceId_SN.paramCode_unit` | 纯常数公式被 API 拒绝（code 501） |
| Manual Metering | 手动抄表录入 | 无硬件依赖 |
| Single Parameter | 单参数设备 | — |
| TOTAL | 系统自动生成，Facility 级聚合 | 不可手动创建 |

## 七、关键约束与测试注意

| 位置 | 注意点 |
|------|--------|
| 设备删除顺序 | Meter Point → Device → Facility；810 网关有下挂设备时禁止删除 |
| Meter Points 过滤器 | 三个 placeholder 均为 "Please Select"，按位置区分：0=Facilities / 1=Devices / 2=Subscription Tier |
| Data Forwards 按钮 | 原文拼写错误：`+Add Data Fowrards`（Fowrards） |
| Calculated 公式 | 纯常数公式（如 "0"）被 API 拒绝，code 501 |
| 未订阅状态 | `/system-menu/tree` 返回 code 603，大多数页面仍可通过 URL 直接访问 |
| 账户锁定 | 连续 5 次密码错误即锁定 |
| 天然气格式 | 非网关：CSV / TOTAL_VOLUME_m3；网关：JSON / TOTAL_VOLUME_cuft（× 0.0283168 → m³） |
| Power Quality Tier | 新建时默认 0，须 SuperAdmin 配置后才可使用 PQ 计量点 |
