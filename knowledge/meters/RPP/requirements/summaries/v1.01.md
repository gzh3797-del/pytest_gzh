## 产品定义

RPP（Remote Power Panel）远程电力面板测量系统。MH（Main Host）为主控单元，通过专有内部总线 AccuBus 连接 VMM（电压测量子模块）和 CMM（电流测量子模块），同时支持南向采集独立 Modbus 设备，并通过多种北向协议对外暴露数据。

**容量边界（两档）**：

| 档位 | MP 总数 | Channel Instance | 双 VMM 镜像 |
|------|---------|-----------------|------------|
| 必须基线 | ≤ 96 | ≤ 96 | 不支持 |
| 期望目标 | ≤ 192 | ≤ 192 | 支持 |

期望目标可行性由架构详细设计评估冻结；Modbus 地址表一律按期望目标最大规模预分配（未启用槽位返 0）。

## §3 通讯

| 类别 | 协议 / 功能 | 优先级 |
|------|------------|--------|
| 私有内部 | AccuBus（时间同步 ≤0.5μs、自发现、数据通信） | 必须 |
| 南向采集 | Modbus TCP/RTU Client（≥32台下挂设备） | 必须 |
| 南向旁路 | Modbus Pass Through（Slave ID 101–247） | 必须 |
| 北向 | Modbus TCP/RTU Server（默认端口 502，支持 Parameters Mapping / Device Mirror 两模式） | 必须 |
| 北向协议转化 | SNMP v2c/v3、BACnet/IP、OPC UA | 必须（OPC UA 期望） |
| 北向数据推送 | MQTT/Email/HTTP/FTP/AcuCloud | 必须 |
| 北向数据推送 | AWS IoT Core、Azure IoT Hub | 期望（下一 Sprint） |
| 基础网络 | HTTPS/DNS/DHCP/NTP/PTP/SFTP/RSTP/Remote Access | 必须 |
| 基础网络 | IPv6 双栈 | 期望（下一 Sprint） |

**数据值类型规则**：
- Modbus Server（PM/DM）+ Pass Through → 原始值（上位机自行乘 Multiplier）
- SNMP/BACnet/OPC UA/MQTT/AcuCloud/HTTP/FTP/AWS/Azure → 工程值（MH 已乘 Multiplier）

**网络接口**：双口 Ethernet（Eth1 默认手动 IP 192.168.8.101；Eth2 默认 DHCP）；RS-485 可配置为南向 Client 或北向 RTU Server。

## §4 虚拟设备

基于物理数据源算术派生（+/−/×/÷），嵌套允许。容量 ≥ 16 台。数据对所有北向协议透明。Modbus Pass Through 数据不可作为虚拟设备输入源。

## §5 测量软件

### 参数体系（五层实体）

| 实体 | ID | 数量 |
|------|----|----|
| VMM | V001 ~ V002 | 1 ~ 2 |
| Channel | CH001 ~ CH096 | 96 |
| Channel Instance | CHnnn.Vk | ≤96（基线）/ ≤192（期望） |
| MP | MP001 ~ MP192 | ≤96（基线）/ ≤192（期望） |
| VMM System | Vk.SYS | 1 ~ 2 |

### 参数分类

- **Realtime**：频率、V_LN/V_LL（RMS+角度）、I（RMS）、∠I（基波）
- **Power**：P/Q/S/PF/Load Nature（归属 CHnnn.Vk / MPnnn / Vk.SYS）
- **PQ**：电压谐波 2~127 次 / 电流谐波 2~63 次 / THD/OTHD/ETHD / Crest / K-Factor / TDD / 不平衡 / 序分量 / Flicker（Pf/Pst/Plt，IEC 61000-4-15）
- **Demand**：电流 Demand（含中性线）/ P/Q/S Demand + Max Demand
- **Energy**：有功/无功/视在电能（Import/Export/Net/Total）

### IEC 61000-4-30 Class A 聚合窗口

10/12 cycle（200ms）→ 3s → 10min → 2h；电压/电流 RMS 与谐波全档必须，Flicker 仅 10min/2h，功率 3s+ 为期望。

### 接线方式

1P2W / 1P3W / 2E3W Network / 2E3W Delta / 3P3W / 3P4W
Neutral Source：None / Calculated / Measured（Delta/2E3W 锁定 None）

### 接线检查（§5.3）

手动触发，检测项：电压相序/缺相/不平衡、电流缺相、CT 极性/反接、电流-电压相位匹配、接线方式与实际匹配、In_meas/In_calc 偏差（默认阈值 5%）。结果仅输出到 Web（v1），Modbus 寄存器保留最近一次快照。

### PQ 事件与录波（§5.5）

检测更新粒度 ≤ 半周期；事件类型：
- 电压：Sag/Swell/Interruption/RVC/过欠压
- 电流：Current Swell/过电流
- 频率：过/欠频率/频率变化
- 暂态：Absolute/Envelope/Rapid increase（仅电压通道）

录波：COMTRADE（必须）/ PQDIF（期望）；存储于 32GB eMMC；采样率电压最高 1024 spc / 电流最高 128 spc。

**v1 PQ 输出渠道**：仅 Web UI + 文件下载（Modbus/SNMP/MQTT 等渠道延后）。

### Max/Min 极值（§5.6）

覆盖 V_LN/V_LL/I/P/Q/S/PF/f/电压不平衡/电流不平衡/电压THD/电流THD；重启保留，可按归属选择性清除。

## §6 本地数据记录

| 功能 | 说明 |
|------|------|
| Datalog | 3 个独立实例，Log Interval ≥ 1s，可配 Post Channel 推送（HTTP/FTP/SFTP），Web 下载/删除 |
| AcuCloud | 预定义字段周期推送 HTTPS，断网本地缓存续推，FIFO 超配额覆盖 |
| Trend Log | 自动启用，固定 5min 周期，覆盖 Energy + Realtime 量（f/VLN/VLL/I/P/Q/S/PF） |

存储共用 eMMC 数据分区，各类别按配额 FIFO；固件升级不擦写数据。

## §7 告警

- **Alarm Monitor**：200 组（固定槽位），AND/OR 逻辑，pickup/dropout 延迟 0~3000ms，通知渠道：Email/Trigger DO/Trigger RO（经 Gateway 下挂 I/O 设备输出）
- **设备告警**：VMM/CMM 离线、Gateway 下挂设备离线，系统自动产生
- **系统级渠道**：Modbus 状态寄存器 + Web（始终）；SNMP Trap（§12 全局开关）
- **按源渠道**：Email、DO/RO（各告警源独立配置）
- **Alarm Log**：≥ 65535 条，含时间戳/来源/持续时间/极值，Web 导出（不经 Modbus）

---

## §8 时间同步

NTP（≥1台）+ PTP（IEEE 1588），两源并存时 PTP 优先；失锁回退 NTP；全失锁由 RTC 维持（漂移 ≤±1s/24h）。AccuBus 下行时间分发精度 ≤0.5μs。时区 + DST 可配。

---

## §9 访问控制

HTTPS Web 通道；默认账户 admin/view；最多 32 用户 / 16 角色；权限粒度 None/View/Edit 按模块配置。Session Timeout 0~60min；失败次数锁定；Password Policy 参考 AcuHMI-1-7。支持 TLS 1.2/1.3，出厂自签名证书，支持用户上传，过期前 30 天提示。

---

## §10 固件升级

| 路径 | 说明 |
|------|------|
| HTTPS Web 上传 | MH 固件，主路径；支持 USB IP-over-USB 访问 Web |
| AccuBus 下行 | MH → VMM/CMM 固件分发 |

固件签名校验；MH 支持 A/B 双分区回滚；VMM/CMM 用 Bootloader 强制升级方案。升级保留全部配置、累计量、日志、录波文件。

## 关键术语

| 缩写 | 含义 |
|------|------|
| MH | Main Host，RPP 主控单元 |
| VMM | Voltage Measurement Module，电压测量子模块 |
| CMM | Current Measurement Module，电流测量子模块 |
| MP | Meter Point，计量点（虚拟电表） |
| AccuBus | MH ↔ VMM/CMM 专有内部总线 |
| Pass Through | Slave ID 101–247，MH 透传不解析 |
