## 产品定位

AcuRev-100 为产品系列名称，当前系列下含 **AcuRev-101-mA**（CT 二次侧 100mA 或 80mA）与 **AcuRev-101-mV**（CT 二次侧 333mV）两个型号。是一款计费级 kWh 子表（Revenue Grade kWh Submeter），开放式电表单元，安装于配电箱内部（需装外壳），通过电压引线与多路 CT 采集电气参数，上报系统控制器（不直接执行电能管理策略）。

**核心功能**：电压直接接入，电流经 80mA/100mA/333mV CT 接入；支持 1E2W/2E3W1P/3E4WY 三种接线；测量各相/系统电压、电流、P/Q/S、能量、PF、频率；LCD 显示/LED 指示/脉冲输出/3.3Vdc 输出（驱动外置 LoRa Pulse 模块）/RS-485 通信/固件升级（Dip Switch 解锁时）。

**认证分层**：
- 电表单元（独立认证）：UL（安全）、CE（IEC 61326-1+EN 55032 Class B）、FCC Part 15 Class B（合规）
- 电表+Panel+CT（系统认证）：MC（精度）、ANSI C12 Class 0.5（自测，不需正式认证）、CTEP（加州型式认证）、NYPSC（纽约州计费）；以 Flush Mount/Surface Mount/MMU 形态进行；须选配 AcuRev-101-mV 型 + 认证 CT（AcuCT-S77-200-333mV 200A / AcuCT-S165-400-333mV 400A）+ 认证 Panel

## 功能模块（按 PRS 章节）

### 3.1 交流电参数测量
- 精度体系：MC S-E-06（认证硬性要求）+ ANSI C12 Class 0.5（自测目标），均针对有功功率/有功电能；其余分量精度（电压/电流 0.2%、无功 0.5% 等）为"建议"设计目标
- 内部计算周期 100ms；电压门限 <10V 视为不存在；启动电流 Ist=0.1%×额定；最小电流 Imin=1%×额定
- 电能累计存储周期 1s（首选）/5s（最低），掉电最多丢 1 个周期

### 3.2 接线
- 三种接线方式（1E2W/2E3W1P/3E4WY），Va/Vn 恒为供电端子
- 接线识别：用户 Modbus 配置，非自适应；Dip Switch 锁定后不可改
- 接线告警：默认启用，周期 1 次/min；判据"实际接线 vs 当前配置"；异常类型：反接、相位错误(±20°以上)、缺相
- 接线配置：电流方向、通道重映射、CT 类型、一次侧额定电流（由 CT Type 隐含）

### 3.3 时间功能
- RTC 漂移 ±0.5s/天，断电保持 1 周（标准 36h 可接受）
- Modbus 配置时间/日期；运行时间/负载时间统计并可重置

### 3.4 通信协议
- RS-485 + USB 双口，各自独立配置波特率/帧格式，共享从站地址，可同时连接
- 波特率 9600–115200bps，默认 19200，8-N-1
- 标准 Modbus RTU：读取（03/04）电压/电流/功率/系统合计/电能/状态/设备信息；配置（06/16）CT类型/额定电流/接线方式/告警开关/从站地址/时间/密码/额定频率/相序/电能计算方式/无功计算方式/脉冲常数/显示分辨率；操作（06/16）reboot/factory reset/clear energy
- 私有协议（RS-485/USB）：仅用于工厂校准与固件升级

### 3.5 固件更新
- 仅 Application 可更新，Bootloader 不可更新且升级中不擦除；配置迁移至新版本
- 经私有协议分包传输+校验；仅接受 Accuenergy 加密签名文件；不支持自动回滚

### 3.6 校准
- 校准电压/电流 RMS 增益、电流相角、ADC 采样频率；50Hz/60Hz 两点；系数存 NVM

### 3.7 脉冲输出与 LoRa Pulse 模块
- 1 路电脉冲（1 imp/kWh）+ 1 路 3.3V 输出，驱动自研或第三方 NextCentury LoRa Pulse 模块实现 AMR
- 脉冲 LED 独立（50imp/kWh 出厂默认，可经 Acuview2 在 0.1–50 范围调），用于认证/现场验证

### 3.8 LCD 显示
- 进线有功电能累计值常显（9位整数+1位小数，分辨率0.1kWh，内部 1Wh）
- 开机序列：公司logo→型号→序列号(MAC(YY+30)MMabcde)→固件版本→接线方式→kWh

### 3.9 铅封
- Dip Switch 位于背面端子侧；锁定后拒绝修改测量/计量相关配置与操作（详见知识库 context.md 必读区）

## 机械/电气/EMC/安全规格要点

| 项目 | 规格 |
|------|------|
| 尺寸 | ≤120×70×70mm，当前设计120×70×54mm |
| 振动 | ANSI C12.1 §4.7.3.20/21；EN 50470-1 §5.2.2.3；测试后误差漂移 ≤±0.1% |
| 冲击 | ANSI C12.1 §4.7.3.18；EN 50470-1 §5.2.2.2；测试后误差漂移 ≤±0.1% |
| 防护等级 | 电表单元开放式不提供防护，外壳应 ≥IP20（Panel 组负责） |
| 端子安全等级 | 电压/电流测量=HLV；RS-485/脉冲输出/3.3V=SELV |
| EMC | 抗扰度 IEC 61326-1；发射 EN 55032 Class B + FCC Part 15 Class B |
| 安全 | UL 61010-1:2012、CAN/CSA C22.2 No.61010-1:2012、UL 61010-2-030 |
| 限制条件 | 关键组件不得使用中国产品；总 BOM 成本(PCBA+结构) ≤15 美元 |

## 工具软件

- **测试台**：仅指示电表执行校准算法（电表自行实现），读取记录结果；工厂配置型号/序列号/接线锁定；工厂验证常规功能（精度/通讯协议）
