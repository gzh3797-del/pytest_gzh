## 产品定位

AcuRev4100 是新一代导轨安装多回路电表，24 路电流输入，12 个用户通道，面向工业/商业分表计量。精度 ANSI/IEC 0.2 级，支持 UL / MC / CE / CTEP / NYPSC 认证。

**型号**：AcuRev-4120-mA（80/100mA CT）/ AcuRev-4120-mV（333mV/RCT）

---

## 功能模块概览

### 3.1 交流电参数测量

| 参数 | 精度 | 说明 |
|------|------|------|
| 频率 | 0.002 Hz | 42.5~69 Hz |
| 相电压 | 0.1% | Van/Vbn/Vcn/avg，Vab/Vbc/Vca/avg |
| 电流 | 0.1% | 24 路输入 + 12 用户通道 + ABC 相及系统 |
| 有功/无功/视在功率 | 0.2% | 各路/用户/相/系统总 |
| 功率因数 | 0.2% | IEC/IEEE 两种格式可配 |
| 谐波 | 1% | 2~31 次（可选 2~63 次）；%/幅度/角度 |
| 不平衡因数 | IEC61557-12 class 1 | 电压、各用户电流 |
| 需量 | — | Block / Sliding Window；记录最大需量及时间戳 |
| 有功/无功/视在电能 | Class 0.2s | 进/出/净/总，update 100ms |

**支持接线方式**：1E2W / 2E3W 1Phase / 2E3W Network / 3E4W Y / 2E3W Delta

### 3.2 分时用电（TOU）

4 费率（尖峰谷平），12 季节，14 时刻表，14 时段，支持 DST / 周休 / 节假日独立配置，每月计费时间可自定义。

### 3.3 电能质量

监控电压 Sag/Swell/Interruption + 电流 Swell，最多 200 条 PQ 事件记录（含波形关联）。

录波：触发 = 手动 / PQ 事件 / DI 变化；采样率 16/32/64/128 sample/cycle；最多 200 组。

### 3.4 告警

20 组告警监控，2 参数 AND/OR 逻辑，含启/释放延迟；最多 200 条告警日志。DO/RO 可配置为告警输出。

### 3.5 记录与统计

- **Max/Min**：带时间戳
- **SOE Log**：DI 状态变化，最多 200 条
- **Data Log**：3 个 datalogger（实时值）+ 1 个 trendlogger（max/min/avg）

### 3.6 Input & Output（本体）

| IO | 数量 | 功能 |
|----|------|------|
| DI | 4 | 状态指示 / 脉冲计数，最大 50Hz |
| DO | 8 | 能量脉冲输出 / 告警指示 |
| RO | 2 | 告警指示 / 继电器控制（Latch/Pulse） |
| AI | — | 0-10V / 0-20mA，3 段分段线性 |
| AO | — | 0-10V / 0-20mA，跟随实时参数 |

### 3.7 时间功能

RTC 断电保持 1 周，漂移 < ±0.5s/天；设备运行时间 / 负载时间记录。

### 3.8 通信协议

- Modbus TCP：以太网，最多 4 个并发客户端
- Modbus RTU：RS485，1200~115200 bps，支持 Sunspec
- BACnet MS/TP：RS485（与 RTU 分时使用）

### 3.9 固件更新 / 铅封 / 校准

铅封封闭时禁止固件更新；标准铅封保护接线/能量脉冲/需量/TOU/算法；校准铁电存储。
