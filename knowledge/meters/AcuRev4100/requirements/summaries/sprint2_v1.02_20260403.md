# AcuRev-4100 Sprint 2 需求摘要 v1.02

**文件**：4100 Sprint 2 软件需求规格书 v1.02 20260403.docx
**日期**：2026-04-03

## 总体目标

在 AcuRev-4100 平台上增加 USB 虚拟串口通信，支持 ACM-41-WEB2 模块通过 USB 对仪表寄存器进行读写，并在 HMI 上增加 WEB2 配置/状态显示。

## 主要需求

### 4.1 USB 虚拟串口通信

- USB 虚拟串口固定配置，支持 Modbus RTU 协议
- 仪表（4100）为从站，WEB2 为主站
- WEB2 可通过 USB 读写 4100 所有寄存器（只读除外）

### 4.2 扩展帧长度（FC 0x66）

- 新增功能码 **0x66**（寄存器长度字段扩展为 2 字节，最大 720 寄存器/帧，单帧最大 1440 字节）
- 适用所有通信接口（含 USB）

### 4.3 WEB2 交互逻辑（状态寄存器机制）

- 4100 设立 **状态寄存器**（32~48 位），各位对应配置项/动作
- Bit=1：需要执行；Bit=0：不动作
- WEB2 定时读取，有效位时读取对应寄存器并配置自身，配置成功后将 Bit 清 0
- 状态寄存器不持久化，4100 上电初始化为 0

### 4.4 HMI 增加 WEB2 配置页面

**可配置**：DHCP / IP / 子网掩码 / 网关 / DNS / 网络模式 / 时间同步

**仅显示**：WEB2 IP2（eth2）/ WIFI IP / 版本 SN MAC

**动作**：重启 WEB2 / 恢复出厂 / 网络默认

确认操作后状态寄存器对应位写 1，标题加 `*`；WEB2 执行后清零。

### 4.5 WEB2 连接状态显示

4100 HMI 液晶右上角显示网络小图标（5 秒内无读取视为断链）。

## 性能要求

USB 通信帧响应时间 < 100ms（目标 < 50ms）。
