## 新增功能模块

### 4.1 电压闪变测试（Flicker）

- 配置：Disable / Automatic（自动匹配权重曲线）/ 手动选择 5 种标准曲线（120V/230V × 50Hz/60Hz × Incandescent）
- 输出：Pinst（3s）、Pst（10min）、Plt（2hr）；各相 A/B/C 独立

### 4.2 Independent Input Channel（独立输入通道）

允许在单表上使用多种类型 CT，灵活配置每路电流对应的计算电压，支持特殊接线（如 3E4W Y 场景下用 Vab 计算某负载功率）。

| 接线方式 | 可选计算电压 |
|---------|------------|
| 1E2W | Van |
| 2E3W 1Phase / Network | Van / Vcn / Vac |
| 2E3W Delta | Vab / Vbc / Vca |
| 3E4W Y | Va/Vb/Vc/Vab/Vbc/Vca |
| 3E4W Delta | Vab / Vbc / Vca |

- **4 路电流通道**（含 N 相）+ **2 个 Summation Channel**（各选 1~4 路）
- 独立模式下，Real-Time/Energy/Demand/Max/Min/DataLog/PQ Event/Waveform 均需按通道可读
- PQ Event：电压事件按接线方式判断，电流事件按通道（I1~I4 Current Swell）
- Waveform：无论独立/非独立，均记录 3V+4I

### 4.3 Dual Source Energy（双源电能）

支持电网（Grid）与光伏（Generation）双源电能分开记录，DI 或通信控制切换方向，含切换日志（时间戳 + 三组能量值）。3 组能量可选基本参数（有功/无功/视在，各相或总）。

### 4.4 Custom Read（自定义读数）

用户配置最多 125 个寄存器地址，支持两级分层读取（Real-Time / Energy / Harmonics-THD / Dual Source / DI Status / Flicker / 多聚合数据）。

### 4.5 SYS Log & Audit Log

- **Audit Log**（铅封保护，不可清除）：计量配置变化（旧值/新值）、铅封状态变化、固件更新、Fatal Error、RTC/ADC/Flash 失败
- **SYS Log**：上电启动、操作/清除记录；各 5000 条，最新在最上面显示

### 4.6 AcuCloud

- 与 DataLog **互斥**（只能一种使能）
- 数据集固定，推送间隔 **5 分钟**，文件格式 CSV
- 文件名：`SN-AcuCloud-UTCseconds-5min.csv`
- 最大本地缓存 1 个月；必须按最旧数据优先推送；仅支持 HTTPS

### 4.7 Data Post

以 Datalog 1/2/3/Trendlog 之一为数据源推送至远端服务器，支持 HTTP / HTTPS（MQTT 暂不实现）。

| 配置项 | 说明 |
|--------|------|
| 文件格式 | JSON / CSV |
| 时间戳格式 | 本地时间 / UTC Seconds / ISO8601 |
| 文件名格式 | Unix Timestamp / Time Interval Format |
| 容量限制 | 单文件估算 ≤ 100KB，超出禁止保存 |

### 4.8 USB 支持 WEB2

第二串口（USB 虚拟串口）配置为 Modbus RTU，供 ACM-41-WEB2 使用；支持 0x66 功能码（720 寄存器/帧）。详见 Sprint 2 需求文档（4100）。

### 4.9 HTTPs Web 页面

- 网页服务器强制 HTTPS，自签名证书烧录进固件
- 功能与上位机软件对齐；支持读数、配置、AcuCloud / Data Post 管理
- 限制：同一时刻仅允许一个 Tab 访问

## 型号差异

| 型号 | 聚合数据 | PQ Event / Waveform | 谐波 |
|------|---------|---------------------|------|
| 1321 | 仅 200ms（10/12 cycle）| 无（隐藏相关页面） | 仅 200ms |
| 1322 | 5 种聚合（1Cycle / 10/12 / 150/180 / 10min / 2hr） | 有 | 4 种聚合谐波 |

---

## 铅封保护

**标准铅封**：接线配置、能量脉冲、需量、PF/VAR 算法、TOU、校准、恢复出厂设置

**非标准铅封（可选）**：RS485 / Ethernet / SNTP 通信配置、运行/负载时间、Dual Source Energy、DI Counter/DO 配置、Independent Input Channel 配置

| Voltage Interruption Hysteresis 默认值 | 1 | 2 | IEC 61000-4-30-2025 |
| PT1 / PT2 默认值 | 690 | 480 | — |
| SNTP 同步间隔下限 | 15s | 60s | — |
| PT2 范围上限 | 690 | 830 | 690V 对 VLL 不够 |
