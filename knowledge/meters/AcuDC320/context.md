# AcuDC-320 — 直流电能表测试项目

## 产品背景

AcuDC-320 是面向直流大电流快充充电桩的直流电能表，符合 MID 认证（EN50470-4 + IEC 62053-41）及 UL 认证。表本体不带显示，搭配分立显示模块（AcuDC-RDU）通过 RS485 连接。支持 OCMF 格式交易日志，可对接充电桩计费系统。

## 功能模块

| 模块 | 说明 |
|------|------|
| 直流电参数测量 | 电压/电流/功率/能量/电荷/纹波因数；20ms + 100ms 双更新 |
| 电缆损耗补偿 | 可配置（启用/禁用 + 电缆电阻 0.0001Ω 精度） |
| 最大/最小测量 | 带时间戳，存非易失内存 |
| 系统模式 | 工厂模式 / 组装模式 / 正常模式 |
| 数据完整性 | 固件/生产信息/计量配置/电能值 CRC32 校验 |
| Echilog（法定计量事件日志） | 最多 6000 条，带 CRC，传输带签名，铅封关闭时不可清除 |
| 交易与交易日志（OCMF） | Modbus 触发开始/停止；250,000 条以上；ECDSA 签名；铅封关闭时不可清除 |
| 计时功能 | RTC 断电保持 1 周；时间同步（偏差 >300s 记日志）；运行/负载时间 |
| 通信协议 | Modbus RTU（RS485，2400~115200 bps）|
| 固件更新 | RS485 上传；铅封关闭时禁止；仅更新 Application |
| 校准 | 工厂模式校准，铁电存储 |
| 分立显示模块（AcuDC-RDU） | RS485 主站，不带按键，11 位能量显示，Idle/Charging 两态 |

## 硬件规格

| 项目 | 规格 |
|------|------|
| 电压输入 | 0~1800V，额定 60~1500V，精度 Class 0.1（首选）|
| 电流输入 | 间接接入 1500A（shunt/磁通门），精度 Class 0.2（首选）|
| 能量精度等级 | EN50470-4 Class 0.5（首选），Class 1（可接受）|
| 供电 | 9~36 Vdc，功耗 ≤6W |
| 通信接口 | RS485 ×2（1 用户通信 + 1 显示模块）|
| 工作温度 | -25°C ~ +70°C |
| 防护等级 | 本体 IP30，安装于 IP51/54 外壳 |
