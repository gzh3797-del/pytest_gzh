## 产品定位

AcuDC-320 是面向**直流大电流快充充电桩**的直流电能表（全新产品），将作为未来 EV 充电主推产品。复用 AcuDC-300 设计，符合 MID 认证（EN50470-4 + IEC 62053-41）及 UL 认证。

**型号**：AcuDC-321-1500V-1500A-P2-RDU（含显示）/ AcuDC-321-1500V-1500A-P2（不含显示）

---

## 外部接口

| 接口 | 说明 |
|------|------|
| 供电 | 9~36 Vdc |
| 电压输入 | 1 路直流，直接连接，范围 0~1800V，额定 60~1500V |
| 电流输入 | 1 路，间接接入（shunt / 磁通门），最大 1500A |
| RS485 | 2 个：1 个用于用户通信（Modbus RTU），1 个用于连接分立显示模块（AcuDC-RDU）|
| LED | 1 个运行指示灯（表本体，绿色 1s 闪烁） |
| HMI | 表本体**不带显示和按键**；外部分立显示模块（AcuDC-RDU）通过 RS485 连接 |
| 铅封开关 | 1 个，设立于表本体 |
| SWD | 工厂编程端口 |
| 温度传感器 | 保留，用于测量精度温度补偿，精度 ±1°C |

## 功能模块

### 3.1 直流电参数测量

| 参数 | 精度 |
|------|------|
| 电压 RMS | 首选 Class 0.1，可接受 0.2 |
| 电流 RMS | 首选 Class 0.2，可接受 Class 1 |
| 功率 | 首选 Class 0.5，可接受 Class 1 |
| 能量 / 电荷 | 首选 EN50470-4 Class 0.5，可接受 Class 1（必须）|

- 电压 / 电流 / 功率 / 能量：提供 20ms 和 100ms 更新参数
- **电缆损耗补偿**：可配置（启用/禁用 + 电缆电阻，精度 0.0001Ω）；补偿后提供 voltage_compensated
- **纹波因数（Ripple Factor）**：对电压和电流分别计算

### 3.3 最大 / 最小测量

记录电压、电流（进/出线）、功率（进/出线）、纹波因数的最大/最小值及时间戳，保存在非易失内存中。

### 3.4 系统模式与数据完整性

| 模式 | 进入条件 | 权限 |
|------|---------|------|
| 工厂模式 | 铅封打开 | 全部修改权限 |
| 组装模式 | 铅封关闭 + 指令 | 仅可修改 Cable Loss（超时退出） |
| 正常模式 | 默认 | 修改通信/显示/时间等 |

**数据完整性校验**：固件 CRC32、生产信息校验、计量配置校验、电能值校验；启动时比较，失败记事件日志。

### 3.5 法定计量事件日志（Echilog）

记录各校验失败、模式/铅封变化、交易日志满、Cable Loss 配置变化、时间同步偏差 >300s、Fatal Error 等。最多 6000 条，带 CRC，传输带签名。铅封关闭时不可清除。

### 3.6 交易与交易日志（OCMF 格式）

- 通过 Modbus RTU 触发开始/停止充电交易
- 每条日志包含：交易 ID、开始/结束时间戳、进/出线电能、充电桩识别信息（OCMF 格式）
- 最多保存 **250,000 条**（>12 年），不可清除（铅封关闭时）
- 支持 ECDSA-secp256r1 签名，带签名读取
- 配置项：私钥/公钥对（工厂模式写入）、充电桩识别类型（EVSEID / CBIDC）、时区和 DST

### 3.7 计时功能

RTC 断电保持 1 周；漂移 <±0.5s/天；支持 Modbus 时间配置；运行时间 / 负载时间记录。

时间同步：充电桩至少每 24 小时同步一次，超差 >300s 记 Echilog。

### 3.8 通信协议

- **Modbus RTU（RS485 用户通信口）**：波特率 2400~115200，支持读取所有测量值、触发交易、读取日志、配置参数
- **HMI 接口（RS485 显示口）**：固定 115200bps，8N1，Modbus Slave ID 1

### 3.9 固件更新

通过 RS485 上传；铅封关闭时禁止；只可更新 Application（不可更新 Boot）；文件加密签名。

### 4. 分立显示模块（AcuDC-RDU）

- 通过 RS485 与表本体通信（Modbus RTU 主站）
- 不带按键，LCD 寿命 ≥12 年，11 位能量显示（分辨率 0.0001 kWh）
- 状态：Idle（显示时间/电能）/ Charging（显示本次电能/时长/EV ID）

UL 61010-1 / MID（EN50470-4 + IEC 62053-41）/ PTB-A 20.1 / PTB-A 50.7 / WELMEC 7.2

| 项目 | 约束值 |
|------|--------|
| 电压输入范围 | 0~1800V（额定 60~1500V） |
| 电流输入 | 间接接入 1500A |
| 供电 | 9~36 Vdc，功耗 ≤6W |
| 工作温度 | -25°C ~ +70°C |
| 防护等级 | 本体 IP30，安装于 IP51/54 外壳 |
| BOM 成本上限 | ≤2045 USD（不含 shunt/磁通门；电流采样器件可放宽至 100 USD）|
