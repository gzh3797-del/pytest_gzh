# 测试设计方法学（共享权威文档）

> 本文件是 `strategy-design` 与 `testcase-design` 两个 skill 共用的测试设计方法学唯一权威来源。
> 两个 skill 通过相对路径引用本文件，**不复制本文件内容**。
> 适用范围：协议类、配置类、UI/Web 类、云上报类功能测试。

本文件回答三个问题：
1. **用什么方法**推导测试点 —— 第一节「方法分类与触发判断」
2. **设计前先想什么** —— 第二节「风险扫描（前置）」
3. **有哪些可复用的成熟场景** —— 第三节「领域专属场景库」

---

## 一、方法分类与触发判断

每个功能在起草测试点前，对照下表判断该叠加哪些方法。**等价类 + 边界值是默认基线**，其余四种按触发条件叠加，不强制全用。

| 方法 | 触发判断（满足即用） | 关键要点 | 落到脑图/用例的方式 |
|------|----------------------|----------|---------------------|
| **等价类划分** | 输入可分类（默认基线） | 每个有效类 + **每个无效类**各取代表值；无效类必须按字段类型补全（见下「按字段类型的强制非法等价类」），不得只取一类 | 有效值 1 组 + 无效值**按字段类型全覆盖**，分属 LV1 / LV2 |
| **边界值分析** | 参数有数值/长度范围（默认基线） | 上点、内点、离点（边界±1）；离点优先取刚超界值。**边界值只解决"数值越界"，负数 / 非数字 / 特殊符 / 空须由等价类清单兜底，二者叠加** | 有效组取最小值/最大值/中间值；无效组取刚超界值 + 等价类清单中其余非法类 |
| **决策表** | **多个条件组合决定结果**（≥2 个独立条件且组合影响输出） | 列全部条件桩与动作桩，覆盖有意义的条件组合 | 每条有意义的规则 → 1 条用例；组合过多时配合正交压缩 |
| **状态转换** | 功能存在**明确状态机**（启停、连接、审核、切换） | 覆盖所有合法状态路径 + 关键非法转换 | 每条状态迁移 → 1 条用例；补 1~2 条非法迁移（LV2/LV3） |
| **正交 / pairwise** | **多因素多水平**组合，全组合会爆炸 | 用正交/成对覆盖压缩组合数，保证两两组合覆盖 | 选正交表生成代表性组合，脑图写明覆盖范围与压缩后用例数 |
| **错误推测法** | 任意功能的补充阶段 | 基于经验推测易错点、薄弱环节、历史 bug 模式 | 推测出的测试点句首加 `[补充]`，多归 LV2/LV3 |

### 按字段类型的强制非法等价类（等价类划分的落地清单）

输入字段一旦可输入非法值，**必须按其类型覆盖下列全部非法等价类**，不得只取"数值刚超界"一类。
**一致性铁律：同一份产物内，同类字段的非法等价类划分必须一致**——不能 A 字段测了负数/特殊符，而同类 B 字段没测（这是最常见的漏测来源）。

| 字段类型 | 典型字段 | 必覆盖的非法等价类 |
|---------|---------|-------------------|
| 数值（端口/数量/时长/计数） | Port、Report Buffer Size、Report Hold Time、APDU Timeout | 超上界、超下界、负数（有效域非负时）、非数字字符（字母）、特殊符（@/#）、空 |
| 字符串/凭证 | RO Community、Username、Password | 空、超长（超字符上限）、特殊符（按需求是否允许）；有长度下限者另测"短于下限" |
| IP / 地址 | Trap Target、Broker Address | 数值超界（999.999.0.1）、纯字母、缺段（192.168.1.）、含端口/多余字符（:162） |
| 枚举 / 下拉 | Version、Auth Protocol、QoS | 无需非法值，仅校验选项集合正确——**不强制套用上面清单** |

> 数值字段有效域非负时，"负数"是独立非法类，**不与"超下界"合并**（-1 与 0 触发的校验分支常不同）。
> 该清单只对"真有该类输入的字段"生效；纯下拉/枚举字段不适用，避免无意义膨胀。

### 三种新方法的典型场景对照（本团队）

- **决策表** → Wiring Check（电压/电流多条件 → Wiring Status 推导）、计费折扣/分级规则、报警触发条件组合。
- **状态转换** → 主连接/备用连接切换、SSL/证书启停联动、云连接（断开→重连→在线）、设备注册/订阅生命周期。
- **正交 / pairwise** → 多协议 × 多设备型号 × 多参数 的兼容性矩阵（如 BACnet/IP × Modbus TCP × 多型号下挂设备同时启用），避免逐一全组合。

## 二、风险扫描（前置）

**在进入分组与起草测试点之前**，先做一遍轻量风险扫描，把扫出的项作为 `[补充]` 测试点的来源。每个功能至少过一遍下列五个维度：

| 维度 | 扫描问题 | 本团队常见落点 |
|------|----------|----------------|
| 潜在缺陷区 | 哪段逻辑最复杂、最易出错？ | 算法推导（Wiring）、单位/缩放系数换算、字节序、时间戳/时区 |
| 用户易错操作 | 用户最可能误配什么？ | 超范围参数、漏配前置开关、证书格式错、地址冲突 |
| 系统薄弱环节 | 哪里资源受限或并发？ | 大量下挂设备、高频轮询、批量操作、弱网/断网 |
| 依赖与前后置 | 有哪些前置条件/级联依赖？ | 开关依赖反向、主备联动、协议依赖、服务重启后状态 |
| 异常恢复 | 异常后能否自愈？ | 断网重连、服务重启、掉电恢复、缓存补传 |

> 扫描产出不要求穷尽，目标是**补齐需求文档没写、但工程经验上必测的点**。
> **但配置类 / 协议通信类功能例外**：「异常恢复」维度的 断网重连、掉电/重启后配置持久化，以及 IPv4/IPv6 双栈接入，属**默认必评项**——每个此类功能都要评估，并在产物中补充对应测试点，或**显式说明为何不适用**（如需求明确不支持 IPv6），不得静默省略。

## 三、领域专属场景库

下列为本团队产品反复出现的成熟测试场景，起草测试点/用例时按功能类型直接取用。**通用 Web 注入类仅适用于真正的 Web 输入（AcuCloud SaaS、设备 Web 页面），嵌入式协议参数不适用。**

### 3.1 配置 / 参数类
| 场景 | 取值/做法 | 建议 LV |
|------|-----------|---------|
| 空值 | 留空保存 → 阻止并提示 | LV2 |
| 超范围 | 刚超下界 / 刚超上界 → 阻止并提示 | LV2 |
| 格式非法 | IP `999.999.0.1`、纯字母、含空格 | LV2 |
| 默认值 | 首次进入展示默认值正确 | LV1 |
| 边界有效值 | 最小值 / 最大值保存成功并生效 | LV1 |
| 唯一性 | 重复名称/地址 → 阻止并提示 | LV2 |
| 开关依赖反向 | 未启用前置开关时，下游字段不可见/不可配 | LV3 |
| 保存后生效 | 配置保存 → 实际行为按新值生效 | LV1 |
| 配置持久化 | 掉电 / 重启后配置不丢失，且按保存值恢复运行 | LV2 |
| 参数功能语义生效 | 参数控制运行时行为者（如缓冲区大小 / 保留时长控制上报节奏），除保存校验外补 1 条"行为按配置生效"用例 | LV2 |

### 3.2 协议 / 通信类
| 场景 | 做法 | 建议 LV |
|------|------|---------|
| 地址越界 | 读写超出地址表范围的寄存器 → 正确报错/拒绝 | LV2 |
| 只读写保护 | 向只读寄存器写入 → 被拒绝 | LV2 |
| 功能码不支持 | 用设备不支持的 FC 请求 → 异常码 | LV2 |
| 字节序/数据类型 | Float32 Big Endian 解析正确，单位/缩放与上位机一致 | LV1 |
| 断连重连 | 拔网/断链后重连 → 通信自动恢复 | LV3 |
| 轮询超时 | 设备无响应 → 超时处理正确，不卡死 | LV3 |
| BACnet 订阅/COV | 订阅后值变化能正确推送（如适用） | LV3 |
| IPv4/IPv6 双栈 | 在 IPv6 网络下重复核心读写/上报流程 → 与 IPv4 行为一致 | LV2 |
| 通信参数不匹配 | 端口 / 社区字符串 / 认证密码与对端不一致 → 请求超时或被拒绝 | LV2 |

### 3.3 云上报类（AcuCloud / AWS IoT / Azure IoT）
| 场景 | 做法 | 建议 LV |
|------|------|---------|
| 上报间隔边界 | Interval 取最小/最大值 → 云端按间隔收到数据 | LV1 |
| 断网缓存补传 | 上报中断网 → 恢复后补传缓存数据 | LV3 |
| 证书/鉴权 | 证书过期/无效、鉴权失败 → 正确报错不上报 | LV2 |
| 时区/时间戳 | 云端时间戳与本地一致（含 UTC/本地切换） | LV2 |
| 多云共存 | 多个云目标同时启用 → 各自独立上报互不干扰 | LV3 |
| 禁用后效果 | 关闭上报 → 云端不再收到数据；重新启用恢复 | LV2 |

### 3.4 Web / SaaS 页面类（AcuCloud、设备 Web 页面）
| 场景 | 做法 | 建议 LV |
|------|------|---------|
| 会话过期 | 长时间无操作 → 重新登录 | LV3 |
| 权限/越权 | 低权限账号访问高权限功能 → 被拒绝 | LV2 |
| 输入注入 | 输入框试 `<script>alert(1)</script>`、`' OR '1'='1` → 被转义/拦截 | LV2 |
| 并发编辑 | 两端同时编辑同一对象 → 冲突处理正确 | LV3 |
| 分页/排序/筛选 | 翻页、排序、筛选结果正确 | LV3 |
| 响应式/兼容 | 不同分辨率/浏览器布局正常 | LV4 |

### 3.5 设备遍历类
| 场景 | 做法 | 建议 LV |
|------|------|---------|
| 多型号下挂 | 遍历支持的设备型号，逐一验证 | 按覆盖范围写明用例数 |
| 多通道 | 遍历全部输入通道（如 24 路电流、8/16 AI） | 写明范围与用例数 |
| 混合下挂 | 多型号 + 多协议混合接入 → 各自正常（配合正交压缩） | LV3 |
