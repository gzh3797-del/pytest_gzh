# CL3021 交流源 串口 / TCP 控源协议说明

> 本文档基于串口精灵实际抓包 + Python 实测验证，完整记录 CL3021 三相交流电源的通信协议。

---

## 1. 设备基本信息

| 项目 | 参数 |
|------|------|
| 型号 | CL3021（响应字符串含 `cl3021`） |
| 接口 | RS-232 / USB 转串口（FTDI VID_0403:PID_6001） |
| 波特率 | 9600 |
| 数据位 | 8 |
| 奇偶校验 | 无（None） |
| 停止位 | 1 |
| 流控 | RTS 常高（RTS_CONTROL_ENABLE），无 CTS/XON/XOFF |

---

## 2. 帧格式总览

### 2.1 通用帧结构

```
[HEAD] [RxId] [TxId] [LEN] [CMD...] [DATA...] [CS]
  1B     1B     1B    1B                         1B
```

| 字段 | PC→设备 | 设备→PC |
|------|---------|---------|
| HEAD | `0x81` | `0x81` |
| RxId | `0x01`（设备地址） | `0x25` |
| TxId | `0x25`（PC地址） | `0x01` |
| LEN  | 总帧长（含所有字节） | 同左 |
| CS   | 校验字节 | 校验字节 |

### 2.2 校验算法

```
CS = byte[1] XOR byte[2] XOR ... XOR byte[n-2]
   = 跳过 HEAD(byte[0]) 和 CS 本身(byte[n-1])，其余所有字节 XOR
```

**示例验证（联机命令）：**
```
帧：81 01 25 06 C9 EB
CS = 01 ^ 25 ^ 06 ^ C9 = EB  ✓
```

### 2.3 数值编码规则

| 物理量 | 编码方式 | 示例 |
|--------|----------|------|
| 电压（V） | `int32_LE = 值 × 10000` | 120V → `80 4F 12 00` |
| 电流（A） | `int32_LE = 值 × 1000000` | 1A → `40 42 0F 00` |
| 频率（Hz） | `int32_LE = 值 × 10000` | 50Hz → `20 A1 07 00` |
| 角度（°） | `int32_LE = 值 × 10000` | 120° → `80 4F 12 00` |

## 3. 命令报文详解

### 3.1 联机命令（Connect）

**长度：6 字节**

```
81 01 25 06 C9 EB
│  │  │  │  │  └─ CS
│  │  │  │  └──── 命令码
│  │  │  └─────── 总帧长=6
│  │  └────────── TxId
│  └───────────── RxId
└──────────────── HEAD
```

**设备响应（41 字节）：**
```
81 25 01 29 [37字节设备ID字符串] [CS]

示例：
81 25 01 29 39 43 4C 54 31 2E 31 2D 63 6C 33 30
32 31 30 30 30 30 30 30 31 2E 30 2D 30 30 30 30
30 30 30 30 61
ASCII: 9CLT1.1-cl3021000001.0-00000000a
```

---

### 3.2 切换 AC 输出版面（AC Screen）

**长度：10 字节**

```
81 01 25 0A A3 00 10 80 01 1C
                           │  └─ CS
                           └──── 01=进入 / 00=退出
```

**退出 AC 版面：**
```
81 01 25 0A A3 00 10 80 00 1D
```

---

### 3.3 设定线制（Set Line）

**长度：10 字节**

```
81 01 25 0A A3 00 01 20 08 A4
```

---

### 3.4 OK 应答（通用响应）

**长度：6 字节**，以上所有命令成功后设备回复：

```
81 25 01 06 30 12
            └──── 0x30 = OK 标志
```

判断标准（任意一条满足即为成功）：
- `rx[4] == 0x30`（6字节OK包）
- `rx[15] == 0x30`（部分长响应包）
- `rx.size > 177 AND rx[4] == 0x50`（读取测量的178字节包）

---

**长度：72 字节**，cmd = `A3 05 46 3F`

```
38      4    ub（B相电压幅值，×10000，LE int32）
42      1    0xFC
43      4    uc（C相电压幅值，×10000，LE int32）
```

### 3.6 幅值实时更新命令（Amplitude Update）

**长度：41 字节**，cmd = `A3 05 44 3F`

```
 1      1    RxId = 0x01

 4      4    CMD  = A3 05 44 3F
 8      4    ua（A相电压，×10000，LE int32）
12      1    0xFC
13      4    ub（B相电压，×10000，LE int32）
17      1    0xFC
18      4    uc（C相电压，×10000，LE int32）
22      1    0xFC
23      4    ia（A相电流，×1000000，LE int32）
27      1    0xFA
28      4    ib（B相电流，×1000000，LE int32）
32      1    0xFA

```

**示例（120V / 0.75A）：**

### 3.7 频率更新命令（Frequency Update）

**长度：14 字节**，cmd = `A3 05 04 C0`

```
偏移  字节数  内容
────  ──────  ────────────────────────────────
 0      1    HEAD = 0x81
 1      1    RxId = 0x01
 2      1    TxId = 0x25
 3      1    LEN  = 0x0E (=14)
 4      4    CMD  = A3 05 04 C0
 8      4    freq（频率，×10000，LE int32）
12      1    0x07（尾部）

```

**示例（50Hz）：**
```

                        └─────────┘
                        50Hz = 500000 = 0x0007A120
```

**示例（60Hz）：**
```
81 01 25 0E A3 05 04 C0 C0 27 09 00 07 A1
                        60Hz = 600000 = 0x000927C0
```

## 4. 控源完整流程

### 4.1 初始化序列（每次连接只做一次）

```
Step 1: 发送联机命令（6B）
        → 等待设备ID响应（41B），验证含 "cl3021"

Step 2: 发送切换AC版面（10B）
        → 等待 OK 响应（6B，byte[4]==0x30）

Step 3: 发送设定线制（10B）
        → 等待 OK 响应
```

### 4.2 控制输出（循环执行）

**每次修改输出参数时，依次发送三条命令：**

```
Step A: 角度+幅值更新（72B）→ OK
Step B: 幅值实时更新（41B）→ OK   ← 实际控制电压/电流的命令
Step C: 频率更新（14B）    → OK
```

> **注意：** 设定值需要发送 **2 个完整周期** 才在测量值中生效（设备内部处理延迟约 1 个更新周期）。

### 4.3 功率因数（PF）控制

PF 通过调整电流角度相对电压角度的滞后量实现：

```
θ = arccos(PF)          # 滞后角度

iaAngle = θ             # A相电流滞后角
ibAngle = θ             # B相电流滞后角（相同值）
icAngle = θ             # C相电流滞后角（相同值）
```

| PF | θ | iaAngle × 10000 | 字节（LE） |
|----|---|-----------------|-----------|
| 1.0 | 0.0° | 0 | `00 00 00 00` |
| 0.8 | 36.87° | 368700 | `BC 9F 05 00` |
| 0.5 | 60.0° | 600000 | `C0 27 09 00` |

### 4.4 断开连接

```
发送退出AC版面命令（10B）：
81 01 25 0A A3 00 10 80 00 1D

关闭串口
```

## 5. 通信时序要求

| 参数 | 推荐值 |
|------|--------|
| 发送后等待时间（extraWaitMs） | 200～500 ms（联机用 500ms，其余用 200ms） |
| RX 队列稳定等待（settleMs） | 100～200 ms |
| 两条命令之间间隔 | ≥ 350 ms |
| PF/量程生效需要的周期数 | 2 个完整更新周期 |

## 6. 串口控制（Python 实现）

```python
import serial, time, struct, math

# ── 端口配置 ──────────────────────────────────────────────
ser = serial.Serial('COM18', baudrate=9600, bytesize=8,
                    parity='N', stopbits=1,
                    timeout=1.0, write_timeout=5.0,
                    rtscts=False, dsrdtr=False)
ser.setRTS(True)   # 对应 C++ dcb.fRtsControl = RTS_CONTROL_ENABLE
ser.setDTR(True)

# ── 校验计算 ──────────────────────────────────────────────
def calc_cs(data):
    cs = 0
    for b in data[1:]: cs ^= b
    return cs

# ── 数值编码 ──────────────────────────────────────────────
def enc_v(v):  return struct.pack('<i', round(v * 10000))    # 电压/角度/频率
def enc_i(i):  return struct.pack('<i', round(i * 1000000))  # 电流

# ── 帧构建 ────────────────────────────────────────────────
def build_connect():
    f = bytearray([0x81, 0x01, 0x25, 0x06, 0xC9])
    f.append(calc_cs(f)); return bytes(f)

def build_ac_screen(enter=True):
    f = bytearray([0x81, 0x01, 0x25, 0x0A, 0xA3, 0x00, 0x10, 0x80, 0x01 if enter else 0x00])
    f.append(calc_cs(f)); return bytes(f)

def build_set_line():
    f = bytearray([0x81, 0x01, 0x25, 0x0A, 0xA3, 0x00, 0x01, 0x20, 0x08])
    f.append(calc_cs(f)); return bytes(f)

def build_angle_update(ua, ub, uc, ia, ib, ic,
                       ua_ang=0, ub_ang=240, uc_ang=120,
                       ia_ang=0, ib_ang=240, ic_ang=120,
                       freq=50.0):
    f = bytearray([0x81,0x01,0x25,0x48,0xA3,0x05,0x46,0x3F])
    f += enc_v(uc_ang) + enc_v(ub_ang) + enc_v(ua_ang)  # 电压角
    f += enc_v(ic_ang) + enc_v(ib_ang) + enc_v(ia_ang)  # 电流角
    f += bytes([0xFF])
    f += enc_v(ua)+bytes([0xFC])+enc_v(ub)+bytes([0xFC])+enc_v(uc)+bytes([0xFC])
    f += enc_i(ia)+bytes([0xFA])+enc_i(ib)+bytes([0xFA])+enc_i(ic)+bytes([0xFA])
    f += enc_v(freq) + bytes([0x07,0x03,0x3F,0x3F])
    f.append(calc_cs(f)); return bytes(f)

def build_amplitude_update(ua, ub, uc, ia, ib, ic):
    f = bytearray([0x81,0x01,0x25,0x29,0xA3,0x05,0x44,0x3F])
    f += enc_v(ua)+bytes([0xFC])+enc_v(ub)+bytes([0xFC])+enc_v(uc)+bytes([0xFC])
    f += enc_i(ia)+bytes([0xFA])+enc_i(ib)+bytes([0xFA])+enc_i(ic)+bytes([0xFA])
    f += bytes([0x02,0x3F])
    f.append(calc_cs(f)); return bytes(f)

def build_freq_update(freq):
    f = bytearray([0x81,0x01,0x25,0x0E,0xA3,0x05,0x04,0xC0])
    f += enc_v(freq) + bytes([0x07])
    f.append(calc_cs(f)); return bytes(f)

BUILD_READ = bytes([0x81,0x01,0x25,0x0F,0xA0,0x02,
                    0x7F,0xFF,0x80,0x3F,0xFF,0xFF,0x0F,0x80,0x39])

# ── 收发 ──────────────────────────────────────────────────
def transact(frame, extra_wait=0.2, settle=0.1):
    ser.reset_input_buffer()
    ser.write(frame)
    time.sleep(extra_wait)
    prev = -1
    for _ in range(20):
        time.sleep(settle)
        n = ser.in_waiting
        if n == prev and n > 0: break
        prev = n
    return ser.read(ser.in_waiting) if ser.in_waiting else b''

def is_ok(rx):
    if len(rx) > 4  and rx[4] == 0x30: return True
    if len(rx) > 15 and rx[15] == 0x30: return True
    if len(rx) > 177 and rx[4] == 0x50: return True
    return False

# ── 初始化 ────────────────────────────────────────────────
transact(build_connect(), extra_wait=0.5)
transact(build_ac_screen(True))
transact(build_set_line())

# ── 设定输出（100V / 1A / 50Hz / PF=0.8）────────────────
UA = UB = UC = 100.0
IA = IB = IC = 1.0
FREQ = 50.0
PF = 0.8
theta = math.degrees(math.acos(PF))

for _ in range(2):    # 发两轮确保生效
    transact(build_angle_update(UA,UB,UC,IA,IB,IC,
                                0,240,120, theta,theta,theta, FREQ))
    transact(build_amplitude_update(UA,UB,UC,IA,IB,IC))
    transact(build_freq_update(FREQ))

# ── 读取测量 ──────────────────────────────────────────────
rx = transact(BUILD_READ, extra_wait=0.5, settle=0.2)
if len(rx) >= 42:
    o = 8
    uc_v = struct.unpack_from('<i',rx,o)[0]/1e6; o+=5
    ub_v = struct.unpack_from('<i',rx,o)[0]/1e6; o+=5
    ua_v = struct.unpack_from('<i',rx,o)[0]/1e6; o+=5
    ic_a = struct.unpack_from('<i',rx,o)[0]/1e6; o+=5
    ib_a = struct.unpack_from('<i',rx,o)[0]/1e6; o+=5
    ia_a = struct.unpack_from('<i',rx,o)[0]/1e6; o+=5
    freq = struct.unpack_from('<i',rx,o)[0]/1e4
    print(f"UA={ua_v:.2f}V  IA={ia_a:.4f}A  f={freq:.1f}Hz")

# ── 退出 ──────────────────────────────────────────────────
transact(build_ac_screen(False))
ser.close()
```

## 7. TCP 控制说明

### 7.1 原理

CL3021 本身是 RS-232 串口设备。TCP 控制需要在设备串口和网络之间加一层转发：

```
[控制程序] ──TCP─── [串口转TCP网关] ──RS232─── [CL3021]
```

常见方案：
- **软件方案**：PC 上运行 com2tcp / RFC2217 串口服务，程序连 `127.0.0.1:PORT`
- **硬件方案**：串口服务器（Serial Device Server）将 RS-232 转以太网，程序连设备 IP

### 7.2 协议字节完全相同

TCP 方式下，**协议帧内容与串口完全一致**，只是传输载体变了：

```python
import socket

# 替换 ser.write / ser.read
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.connect(('192.168.1.100', 4001))   # 串口服务器 IP:PORT
sock.settimeout(2.0)

def transact_tcp(frame, wait=0.5):
    sock.sendall(frame)
    time.sleep(wait)
    try:
        return sock.recv(4096)
    except socket.timeout:
        return b''
```

### 7.3 TCP 与串口差异对比

| 项目 | 串口 | TCP |
|------|------|-----|
| 协议帧内容 | 完全相同 | 完全相同 |
| 连接方式 | `serial.Serial('COM18', 9600)` | `socket.connect(IP, PORT)` |
| 流控 | RTS 常高 | 网关处理，程序无需关心 |
| 超时处理 | write_timeout | socket.settimeout |
| 排他访问 | 同一时刻只能一个程序打开 | 取决于网关配置 |

## 8. 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `PermissionError: Access Denied` | 另一程序已打开 COM 口（如 TestBench.exe）| 关闭占用程序 |
| 联机成功但设定无效 | 只发了 72B 帧，缺 41B 幅值帧或 14B 频率帧 | 三条命令必须都发 |
| 设定值滞后 1 个周期 | 设备内部处理延迟 | 发 2 轮后再读测量 |
| 写超时（Write Timeout） | CTS 信号未就绪或流控设置错误 | 确认 `fOutxCtsFlow=0`，禁用 RTS/CTS |
| 联机响应 41B 但 `looksLikeOk` 返回 false | 字节解析偏移错误 | 检查 `rx[15]==0x30`（连接响应走第二判断分支）|
| 拔插 USB 后端口号变化 | FTDI 枚举分配了新端口号 | 查设备管理器确认新端口号 |
