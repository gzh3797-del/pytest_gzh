## 一、产品概述

AcuHMI-1-7 是工业级 HMI 网关一体机（7" 电容触屏）。南向采集 Accuenergy 系列电表（RTU/TCP），北向通过 8 种协议推送至上位机/云平台。

| 接口 | 规格 |
|------|------|
| 触屏 | 7" TFT 800×480 电容触控 |
| RS485 | 2 路独立（COM1/COM2）Modbus RTU |
| 以太网 | 2×100 Mbps RJ45；Eth1 默认静态 192.168.8.101/24，Eth2 默认 DHCP |
| 扩展 | H-IO（8DI+8RO），自动识别接入 |
| 电源 | 9~36 VDC，功耗 ≤6 W |

## 二、功能模块一览（13 个模块）

### M-01 登录与用户权限

| 项目 | 约束 |
|------|------|
| 默认账号 | admin（Admin@ + SN末6位）/ view（View@ + SN末6位），均不可删除 |
| 用户上限 | 32 个 |
| 角色上限 | 16 个；权限粒度 None/View/Edit，覆盖 9 个功能域 |
| 密码策略 | 9 项：字符格式/历史(1~32)/最小使用天/过期(0~90天)/长度(6~64)/宽限期/最大失败次数(0~30)/失败窗口/锁定等待 |
| 首次登录 | 默认密码强制修改；登录后必须接受 EULA |
| 忘记密码 | admin 专用：凭设备日期+SN生成当日临时密码；非 admin 引导联系管理员 |
| 会话超时 | 0~60 分钟；实时数据采集页面豁免 |

### M-02 设备管理

| 类型 | 上限 | 关键说明 |
|------|------|---------|
| 物理设备（RTU/TCP） | 32 台 | Device Name/SN/模板/协议参数；Add to Logger 直接分配 |
| 虚拟设备 | 32 个 | 四则运算公式；SN 自动生成"AEVM"+5位随机数；计算间隔 5~15 秒 |
| Web 设备 | 100 个 | 聚合第三方 Web 入口；20 秒超时未加载时弹警告 |
| H-IO | 1 个 | 自动接入，提供 8DI+8RO；支持告警 Trigger RO/DO 1~8 |

**模板切换约束：** 仅允许同型号内（同 Model 不同 Version）；切换时弹窗确认对虚拟设备的影响。

### M-03 数据测量与展示

- **Metering**：Realtime/Demand/Energy；AcuRev-4100 支持 User Channel 1~12（Description ≤20 ASCII）
- **PT1/PT2**（AcuRev-4100）：PT1: 50~1,000,000，PT2: 50~830，约束 PT1 ≥ PT2 ≥ Nominal Voltage ≥ 50
- **THD/Harmonics**：2~63 次；Sequence：正/负/零序及不平衡度
- **PQ Event**：ITIC/CBEMA/SEMI 曲线报告（HMI 仅事件清单，不支持曲线生成）
- **Waveform**：列表+可视化；左轴电压/右轴电流；HMI 仅查看与删除，下载须在 Web
- **Trend Log**：Realtime/Energy 两类；Time Interval 5/10/15/30min、1/6/12h；最多 4 参数同屏对比；支持 Checkpoint 切换历史备份

### M-04 告警管理

- Alarm Config：每设备独立配置参数阈值 + 设备离线告警 + Trigger DO/RO（H-IO）
- **未确认告警页**：Alarm Acknowledgement Enable 时展示；Acknowledge 后从页面移除并在 Alarm Log 追加确认记录
- **蜂鸣器**：仅当存在未确认告警时响；全部确认后自动停止
- 邮件通知：最多 3 个收件人，Email Interval 1~10 分钟

### M-05 数据日志与文件推送

| 项目 | 约束 |
|------|------|
| Data Logger | 3 个标准 + 1 Rapid Logger（最小间隔 1 秒） |
| Post Channel | 3 条（FTP/SFTP/HTTP/HTTPS）；单 Channel 设备数上限 16；单 Channel 配额 4 GB |
| 单 Logger 设备数 | ≤ 32 |
| 板载存储 | 32 GB |
| 参数默认选中 | 物理设备：Realtime（电压/电流/功率/频率）+ Energy（进出线有功能量）；虚拟设备：全部参数 |
| AcuCloud Log Interval | **固定 5 分钟**（Sprint 3 起删除该配置项） |
| AcuCloud Advanced | Web URL 追加 `?showAdvanced=true` 可修改服务 URL；HMI 不支持 |
| 历史数据补推 | 按设备+时间段+格式，不影响实时 Logger |

### M-06 北向 Modbus TCP

| 子功能 | Slave ID | 说明 |
|--------|---------|------|
| Device Information | 1 | 网关+下挂设备元数据，只读 |
| Parameters Mapping | 100（固定） | 统一地址空间；Quick Sort 自动分配连续地址 |
| Device Mirror | 2~99 | 每台设备独立 Slave ID；支持 Download All |
| Pass Through | 101~247 | 透明代理，不修改数据段 |

- Modbus Port 默认 502，可配置范围 **2000~5999**
- Modbus 全局 Disable 时三种子功能均不可启用

### M-07 北向 SNMP / BACnet/IP

**SNMP：**
- v2c（RO Community）/ v3（Auth: MD5/SHA，Privacy: DES/AES/None）
- Port 默认 161，可配置范围 **16100~16199**
- Trap：最多 4 个目标；Buffer Size 0~30；Hold Time 0~300 秒
- 支持 MIB 文件下载

**BACnet/IP：**
- Port 默认 47808，范围 **47808~49000**；Device Instance 0~4194302
- APDU Timeout 3~60 秒（默认 3），Retries 0~10（默认 2）
- COV：仅在 Polling Enable 时可启；Increment ≥ 0.000，最多 3 位小数
- Foreign Device → 外部 BBMD 注册（TTL 5~1440 分钟）；Full BBMD 作为后续扩展
- Harmonic 参数支持所有电表型号；EPICS 文件下载

### M-08 北向 MQTT / AWS IoT / Azure IoT

| 协议 | 关键配置 |
|------|---------|
| MQTT | General/Credential/SSL-TLS/LWT/Topic；Interval: 1~600秒(11档)；Payload: JSON（timestamp+comm_head+devices数组） |
| AWS IoT | URL 仅允许小写字母+数字+"-.:/"; 缓存 **24~72 小时**；Interval: 1~600秒(11档) |
| Azure IoT | Primary/Secondary Connection String；支持 Device Twin；SSL 可选；Primary 不可达自动切 Secondary |

MQTT Payload 格式：`{ "timestamp": ..., "comm_head": {name/model/sn}, "Devices": [{name/model/sn/online/reading[]}] }`

### M-09 模板管理

- 官方模板：随固件发布，只读；自定义模板：基于 Typical Energy Meter V2
- 命名规则：`TemplateName_版本号_Firmware_版本号`（Firmware 仅显大版本如 v1.03）
- 支持 .def 加密文件导入/导出；同名同版本（或更低）不允许导入
- 向后兼容；网关升级后按 Firmware Version 自动匹配模板

**支持电表固件版本：**

| 电表 | 固件 |
|------|------|
| AcuRev-4100 | ACCUENERGY v1.03 |
| AcuRev-2100 | AcuRev2100 v1.20 |
| AcuRev-1300 | AcuRev1300 v2.24 |
| Acuvim II | IIV3 v6.36 / LV4 v6.36 |
| Acuvim 3 | v1.03p19 |

### M-10 系统配置

- **网络**：Eth1 默认 192.168.8.101/24/GW:192.168.8.1（DHCP Disable）；Eth2 默认 DHCP Auto；DNS1 8.8.8.8/DNS2 8.8.4.4；RSTP 默认 Disable
- **Access Control**：IP Allow List（单 IP 或 IP 段，OR 逻辑组合）
- **证书管理**：Import/Export/Generate CSR/Generate Self-Signed；导入/生成后强制重新登录
- **配置导入导出**：加密二进制；可选 System/User/Devices 三类；出厂复位（admin 权限，二次确认）

### M-11 远程访问

- 注册/注销 URL；Ping Interval 60s/600s（默认 60s）
- Advanced 模式：Web URL 追加 `?showAdvanced=true` 可修改后端 URL；HMI 不支持
- view 用户不可触发注册/注销（Sprint 2 已修复越权问题）

### M-12 系统维护与诊断

- System Status：CPU/RAM/磁盘占用；Reboot
- Event Log：Level(Critical/Error/Info)；导出 CSV；FIFO 清理
- **Modbus Debug Log**：TCP/RTU 请求响应帧记录；仅 Web
- **SSH**：默认 **Disable**；Port 22 或 6000~9999；闲置 30 分钟自动断开
- **Wiring Check**：见下节

### M-13 固件升级与安全合规

- 固件包 .a2h；禁止降级（提示 "Firmware downgrade is not allowed."）
- 升级失败 → Emergency Mode 回退到上一版本
- 出厂安全默认：SSH/Modbus北向/Remote Access/AcuCloud/AWS/Azure/MQTT/SNMP/BACnet 全部 **Disable**
- Data Logger 1/2/3 + Rapid Logger 默认 **Disable**

| 3E4WY | ✅ | ✅ | ✅ | ✅ | ✅ |
